# Contributing

Print reports, photos and measured fit improvements are welcome. Please open
an issue with the design name, release version, printer, nozzle, filament,
layer height and whether you changed the supplied profile.

For clip feedback, start with the supplied coupon. Describe whether assembly
was loose, comfortable, overly tight or caused cracking, and where. A useful
report includes dimensions or close-up photos and the number of assembly
cycles tried. Geometry checks cannot replace these measurements.

For changes to the model, include a drawing or actual-mesh render, fit checks,
and the matching front and back. Run `python3 tools/verify_release.py` for
changes to the distributed collection. A revised model needs a corresponding
new slicer report and checksum; keep prior results distinct.

Code contributions use MIT. Design contributions use CC0 1.0. Please only
contribute material you have the right to share, and record external inputs
and AI assistance in the provenance notes.

## Print photos

Real print photos will be added after physical testing. You can attach yours
to an issue or add them under `photos/` in a pull request. A straight-on view,
an oblique view and a rear detail are particularly useful. Include the design
name and your print settings.

Photos need an explicit permission record; see [photos/README.md](photos/README.md).
You do not need to show personal photographs or faces: a blank paper dummy
works well for documenting the frame and its fit.
